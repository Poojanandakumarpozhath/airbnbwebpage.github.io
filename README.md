# Airbnb Website

## Overview
This project is a simple Airbnb-style website built using **HTML, CSS, and JavaScript**. It allows users to browse rental listings, view property details, and interact with a responsive user interface.

## Features
- **Property Listings:** Display available properties with images, descriptions, and prices.
- **Search & Filtering:** Users can search properties based on location, price, and other criteria.
- **Responsive Design:** The site adapts to different screen sizes for a seamless user experience.
- **Interactive UI:** JavaScript enhances interactivity, such as dynamic content loading and user interactions.
- **Booking Simulation:** Allows users to select a property and proceed with a booking simulation.

## Technologies Used
- **HTML5**: Structure of the website
- **CSS3**: Styling and layout
- **JavaScript**: Interactive elements and dynamic content
